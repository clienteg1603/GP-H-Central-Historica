REVISÃO v0.34.0 — SERVIDOR DE ATUALIZAÇÕES
--------------------------------------------
- Cliente preparado para hospedagem HTTPS estática, sem depender do provedor.
- update_manifest.json pode apontar para pacote por URL relativa; a mesma pasta de release pode ser movida para outro host sem refazer o ZIP.
- Canais Estável e Teste são mantidos simultaneamente no manifesto.
- Suporte a espelhos de download para contingência.
- HTTP remoto é bloqueado; HTTP só é aceito em localhost para testes.
- Manifesto limitado a 1 MiB e pacote a 600 MiB.
- Configurações permite informar/testar o endereço do servidor uma única vez; o valor fica salvo em %LOCALAPPDATA%.
- CRIAR_PACOTE_ATUALIZACAO.py gera a estrutura pronta para publicação: update_manifest.json + releases/GP-H_update_vX.Y.Z.zip.
- Teste fim a fim local validado: manifesto via HTTP localhost -> resolução da URL relativa -> download -> SHA-256 -> leitura do pacote -> instalação -> backup -> rollback.
- Interface abriu em smoke test Tkinter/Xvfb sem erro de inicialização.
